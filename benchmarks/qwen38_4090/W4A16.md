# Native SM89 W4A16 decode operator

This is an operator-only record for the first real Qwen3.8 projection executed
by ApxInf. It does not establish a native model or serving win.

## Contract

```text
GPU:              NVIDIA GeForce RTX 4090, SM89, 128 SMs
CUDA / cuBLAS:    12.3 / 12.3.2
model revision:   63768c10df38c0395e12ef49edac1bd539eaeeea
tensor:           model.language_model.layers.0.mlp.gate_proj
logical weight:   [17408, 5120]
activation:       BF16 [1, 5120]
output:           BF16 [1, 17408]
packed weight:    I32 [17408, 640]
scale:            BF16 [17408, 160]
zero point:       I32 [2176, 160]
quantization:     W4, group 32, asymmetric, compressed-tensors offset-binary
timing:           no profiler, caller-owned output, one CUDA stream
```

The loader reads only these three payload tensors plus the 16-byte logical
shape; it does not materialize the full checkpoint or a BF16 weight copy.

The correctness oracle follows compressed-tensors 0.17.0 exactly:

```text
q  = ((packed_weight >> 4*nibble) & 0xf) - 8
zp = ((packed_zero  >> 4*row_mod_8) & 0xf) - 8
w  = (q - zp) * bf16_scale[row, column/32]
y  = bf16_round(sum_k(bf16_activation[k] * w[row,k]))
```

All measured implementations produced:

```text
cosine       0.9999999999929166
relative L2  3.7638899466649766e-6
max abs      0.00006103515625
finite       true
```

## Implementations

`generic-direct` was the initial kernel. One block owns eight output rows and
one warp owns each row, but group size remained a runtime parameter. SASS
contained generic division machinery and `MUFU.RCP` despite the Rust gate only
allowing group 32.

`direct` specializes group 32 at compile time. It removed the generic reciprocal
mechanism, retained 39 registers, and used no spill, local, static shared, or
stack memory. It directly loads activation, scale, and zero-point data while
streaming the packed weight.

`staged` keeps the same weight ownership but cooperatively loads the 10 KiB
activation, eight rows of scales, and one row-pack of zero points into 13,440
bytes of dynamic shared memory. It adds one CTA barrier, uses 40 registers, and
has zero spill/local/stack memory. The staged arm is now the Rust API default;
`w4a16_write_direct` remains the explicit rollback.

## Results

Single-session detailed runs:

| arm | hot-L2 median | cold-HBM proxy median | CV hot / cold | result |
|---|---:|---:|---:|---|
| generic-direct | 43.7551 us | not measured | 0.190% / - | replaced by constant specialization |
| direct | 31.6466 us | 90.0995 us | 0.0576% / 0.599% | accepted baseline |
| staged | 29.1354 us | 84.2945 us | 0.0720% / 0.441% | candidate passed |

The hot measurement performs 30 blocks of 100 calls after 20 warmups. The cold
proxy performs a 128 MiB stream memset and synchronization outside the timed
region, then times one launch through stream synchronization for each of 30
samples. The projection's minimum physical inputs total 51,527,680 bytes
(49.140625 MiB); the staged cold median corresponds to about 611 GB/s before
subtracting host launch/synchronization cost. This is a proxy, not an NCU DRAM
counter.

The staged admission thresholds were frozen before execution:

```text
correctness unchanged
cold median <= 85.575 us (at least 5% better than 90.079 us)
hot median  <= 32.229 us (no more than 2% regression from 31.597 us)
```

It passed both. A five-pair alternating AB/BA process screen then reported:

```text
hot staged wins       5/5
cold staged wins      5/5
median hot speedup    1.0961804862x
median cold speedup   1.0692648908x
decision              promote-staged-operator-default
end-to-end promoted   false
```

The screen's direct cold medians were 90.2095, 90.2295, 90.3645, 90.1540, and
90.1190 us. Staged cold medians were 84.3340, 84.4700, 84.2895, 84.3140, and
84.4990 us.

## Decision and next boundary

Decision: promote staged as the **operator default**, keep direct as rollback,
and continue. This is not an end-to-end promotion.

The next operator coverage must include every distinct `(K,N)` projection shape
and the M>1 prefill path. The next architectural boundary is a complete Qwen3.8
GDN layer with named endpoints for projection outputs, convolution state,
recurrent state, final output, input immutability, and 128-step mutated-state
replay. A 64-layer text timing or vLLM comparison is invalid before those gates.
