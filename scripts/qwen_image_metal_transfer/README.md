# Qwen Image source references

These maintained transfer references preserve exact historical Python/MLX and embedded MSL source bytes.
They are excluded from the Rust runtime and model registry. Select them by the evidence and storage rules in
[the transfer guide](../../doc/qwen-image-metal-transfer/README.md).

`verify_bundle.py` checks manifest hashes and Python syntax without executing candidates.
The original repositories retain raw experiment data. This directory contains no weights or captures.
